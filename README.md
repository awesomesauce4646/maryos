# maryOS

A web-based desktop! 

Made for the Hack Club Stardance challenge, and for the WebOS mission.

## About
maryOS is a desktop that is completely client-sided.

## Features

- Desktop Environment
- Drag and close windows
- Top bar with a clock and date
- Note app that saves with local storage
- Game link window
- Welcome window
